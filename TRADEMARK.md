# Name and logo

"Supalens" and the Supalens logo (the files under `branding/`) identify the project and the
hosted service at supalens.ai. The AGPL-3.0 licence that covers the code does not license them.

You may:

- say that your deployment runs Supalens, and link to the project;
- use the name and logo unchanged inside a self-hosted install for your own team.

Please do not:

- offer a hosted service or a modified distribution under the Supalens name or logo;
- use them in a way that suggests the project endorses or operates your product.

If you redistribute a modified version, give it a different name and logo. Questions:
admin@supalens.ai.
